Simulating Black Hole Gravity

Dr. Nova
12.5K Followers

In this simulation, we use the Schwarzschild metric to visualize how light bends around a black hole. This was built using Manim and Pymunk for the particle physics integration.

Click "Remix Code" to open this exact simulation in the XtraAnim Studio and change the mass of the black hole!

Source Code Preview

class BlackHoleSim(Scene): def construct(self): # Create the Event Horizon horizon = Circle(radius=2, color=BLACK, fill_opacity=1) horizon.set_stroke(WHITE, width=1) # Accretion Disk disk = Ellipse(width=6, height=2, color=ORANGE) disk.set_fill(ORANGE, opacity=0.5) self.play(Create(horizon), FadeIn(disk)) self.wait(2)
